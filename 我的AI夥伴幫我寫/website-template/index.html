模板

簡潔的倉庫式網頁

這個範本把 GitHub 倉庫的資料夾結構直接映射成網站導覽，先保留乾淨的版面與清楚的層級。

首頁區塊

可放最新內容、常用分類、最近更新、或固定導覽入口。

文章區塊

每個內容頁維持相同版型，方便以後直接批次套用。

麵包屑

用資料夾路徑生成目前位置，讀者可以快速回到上層。

後續可調整

字體、側欄寬度、卡片密度、是否要顯示完整樹狀結構。
